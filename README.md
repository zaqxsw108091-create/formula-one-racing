# Formula One World Championship

Unity로 제작한 3D 레이싱 게임입니다. 플레이어가 수동 변속으로 차량을 조작하여 AI 차량들과 5바퀴 경주를 벌입니다.

---

## 실행 방법

### 필요 환경
- **Unity 6000.0.32f1** (Unity 6)
- Unity Hub

### 실행 순서
1. 이 저장소를 다운로드합니다.
   ```bash
   git clone https://github.com/zaqxsw108091-create/formula-one-racing.git
   ```
   (또는 `Code ▸ Download ZIP`)

2. **Unity Hub ▸ Add ▸ Add project from disk** 에서 다운로드한 폴더를 선택합니다.

3. 프로젝트를 엽니다. (첫 실행 시 에셋 임포트에 5~15분 정도 걸립니다.)

4. Project 창에서 **`Assets/Scenes/SampleScene.unity`** 씬을 엽니다.

5. 상단의 **▶ (Play)** 버튼을 누르면 게임이 바로 시작됩니다.

### 운전 요령
차량은 **수동 변속**입니다. 기어마다 낼 수 있는 최고 속도가 정해져 있어, 더 빨리 달리려면 반드시 `E`로 기어를 올려야 합니다.

**1단으로 출발 → 화면의 기어별 최고속에 가까워지면 `E`로 업시프트 → 반복**

| 기어 | 최고 속도 |
|---|---|
| 1단 | 약 71 km/h |
| 2단 | 약 99 km/h |
| 3단 | 약 136 km/h |
| 4단 | 약 189 km/h |
| 5단 | 약 246 km/h |
| 6단 | 300 km/h |

## 화면 정보 (HUD)

**화면 왼쪽 — 내 차량 상태**
- `Speed` : 현재 속도
- `Gear` : 현재 기어와 해당 기어의 최고 속도
- `Boost` : 부스터 잔량 (사용하면 줄고, 안 쓰면 자동 충전)
- `0→100` : 정지 상태에서 100km/h까지 걸린 실측 시간

**화면 오른쪽 — 레이스 정보**
- `Lap` : 현재 바퀴 수 / 총 5바퀴
- `Time` : 경과 시간
- `Ranking` : **실시간 등수** (완주자 우선 → 진행도 순)

플레이어가 5바퀴를 완주하면 레이스가 종료되고 화면 중앙에 **최종 순위**가 표시됩니다.

## 구현 기능

### 차량 물리 / 드라이브트레인
- Unity `WheelCollider` 기반 서스펜션 및 타이어 마찰 시뮬레이션
- **RPM-토크 곡선** 적용 — 저회전은 약하고 중회전에서 피크, 레드존에서 하락하는 실제 엔진 특성
- **6단 변속기** — 기어비에 따라 저단은 가속력이, 고단은 최고속이 높아짐
- 기어별 최고 속도 제한
- 안티롤바(Anti-roll bar)로 코너링 시 차체 롤 억제
- 무게중심 조정으로 전복 방지
- 속도에 따른 엔진 사운드 피치 변화

### 플레이어 기능
- 수동 변속 (순차 변속 + 직접 선택)
- 부스터 — 게이지 소모 및 자동 충전, 사용 중 최고속 일시 초과 허용
- 드리프트 — 그립을 낮추고 뒷바퀴 핸드브레이크 적용
- 0→100km/h 가속 시간 실시간 측정

### AI 주행
- **웨이포인트 추종** — 트랙 경로를 순서대로 통과하며 주행
- **코너 예측 감속** — 다가오는 코너의 꺾임 각도와 거리를 계산해 미리 브레이크
- **충돌 회피** — `SphereCast`로 전방 차량을 감지해 감속 및 회피 조향
- **뭉침 방지** — 차량마다 좌우 주행 라인과 최고 속도에 편차를 부여
- 속도 기반 자동 변속

### 레이스 시스템
- 웨이포인트 통과 기반 랩 카운트 (총 5바퀴)
- 실시간 순위 계산 — 완주 차량은 완주 시간순, 미완주 차량은 트랙 진행도순
- 레이스 종료 시 최종 순위 표시

## 스크립트 구조

경로: `Assets/Script/`

| 파일 | 설명 |
|---|---|
| `PlayerCarController.cs` | 플레이어 차량 — 입력 처리, 수동 변속, 부스터, 드리프트, 차량 물리 |
| `ComputerCarController.cs` | AI 차량 — 웨이포인트 주행, 코너 감속, 충돌 회피, 자동 변속 |
| `GameManager.cs` | 레이스 진행 관리 — 실시간 등수 계산, 랩 추적, HUD 표시 |
| `LapTracker.cs` | 랩·진행도 추적기, `IRaceCar` 인터페이스, 엔진 토크 곡선 모델 |
| `WaypointPath.cs` | 트랙 경로 정의 헬퍼 — 자식 오브젝트를 자동으로 웨이포인트로 인식, 씬 뷰 시각화 |
| `GameMenuManager.cs` | 메뉴 UI 관리 (현재 씬에서는 비활성) |

## 트랙 경로 편집 (선택 사항)

AI 주행 경로를 더 촘촘하게 만들고 싶다면:

1. 빈 GameObject를 만들고 `WaypointPath` 컴포넌트를 추가합니다.
2. 그 **자식**으로 빈 오브젝트를 트랙을 따라 순서대로 배치합니다. (첫 자식 = 출발/결승선)
3. Scene 뷰에 경로가 청록색 선으로 표시되어 눈으로 확인하며 조정할 수 있습니다.
4. 컴포넌트의 톱니바퀴 메뉴 ▸ **"웨이포인트 촘촘하게"** 를 누르면 중간점이 자동 삽입됩니다.

경로를 별도로 만들지 않으면 씬에 이미 배치된 웨이포인트를 자동으로 사용합니다.
