# Formula One World Championship

Unity로 제작한 3D 레이싱 게임입니다. 플레이어가 수동 변속으로 차량을 조작하여 AI 차량들과 5바퀴 경주를 벌입니다.

---

## 실행 방법

### 필요 환경
- **Unity 6000.0.32f1** (Unity 6)
- Unity Hub

### 실행 순서
1. 이 저장소를 다운로드합니다.
   ```bash
   git clone https://github.com/zaqxsw108091-create/formula-one-racing.git
   ```
   (또는 `Code ▸ Download ZIP`)

2. **Unity Hub ▸ Add ▸ Add project from disk** 에서 다운로드한 폴더를 선택합니다.

3. 프로젝트를 엽니다. (첫 실행 시 에셋 임포트에 5~15분 정도 걸립니다.)

4. Project 창에서 **`Assets/Scenes/SampleScene.unity`** 씬을 엽니다.

5. 상단의 **▶ (Play)** 버튼을 누르면 게임이 바로 시작됩니다.

### 운전 요령
차량은 **수동 변속**입니다. 기어마다 낼 수 있는 최고 속도가 정해져 있어, 더 빨리 달리려면 반드시 `E`로 기어를 올려야 합니다.

**1단으로 출발 → RPM이 레드존(9,000 이상)에 가까워져 화면에 `SHIFT UP (E)`가 뜨면 `E`로 업시프트 → 반복**

기어 안에서 속도가 오를수록 RPM이 올라가고(엔진음도 높아짐), 기어를 올리면 RPM이 뚝 떨어집니다. 엔진 힘은 중간 RPM에서 가장 세고 레드존에서는 약해지므로, 레드존 근처에서 올려 주는 것이 가장 빠릅니다.

기어를 올리지 않고 최고 RPM(10,000)에 닿으면 **회전수 제한기(리미터)** 가 작동합니다. 엔진 힘이 짧게 끊겼다 이어지기를 반복해서 RPM 바늘과 엔진음이 떨리고, 그 기어의 최고속보다 빨라지지 않습니다. 화면에 `LIMITER - SHIFT UP (E)`가 뜨면 기어를 올리라는 뜻입니다.

| 기어 | 최고 속도 |
|---|---|
| 1단 | 약 71 km/h |
| 2단 | 약 99 km/h |
| 3단 | 약 136 km/h |
| 4단 | 약 189 km/h |
| 5단 | 약 245 km/h |
| 6단 | 300 km/h |

## 화면 정보 (HUD)

**화면 왼쪽 — 내 차량 상태**
- `Speed` : 현재 속도
- `RPM` : 엔진 회전수 (레드존 근처에서 `SHIFT UP (E)`, 리미터에 걸리면 `LIMITER` 표시)
- `Gear` : 현재 기어와 해당 기어의 최고 속도
- `Boost` : 부스터 잔량 (사용하면 줄고, 안 쓰면 자동 충전)
- `0→100` : 0→100km/h 가속 기록. **멈춘 상태에서 가속 키를 떼지 않고 100km/h에 도달**하면 기록됩니다. 출발 전에는 안내 문구, 측정 중에는 흐르는 시간, 측정이 끝나면 기록이 표시됩니다. (중간에 가속 키를 떼면 측정이 취소되고, 다시 멈췄다가 출발하면 새로 잽니다. 1단 최고속이 71km/h라서 기어를 올려야 100에 도달합니다.)

**화면 오른쪽 — 레이스 정보**
- `Lap` : 현재 바퀴 수 / 총 5바퀴
- `Time` : 경과 시간
- `Ranking` : **실시간 등수** (완주자 우선 → 진행도 순)

플레이어가 5바퀴를 완주하면 레이스가 종료되고 화면 중앙에 **최종 순위**가 표시됩니다. 이때 `Enter`를 누르면 처음부터 다시 시작합니다.

## 구현 기능

### 차량 물리 / 드라이브트레인
- Unity `WheelCollider` 기반 서스펜션 및 타이어 마찰 시뮬레이션
- **RPM-토크 곡선** 적용 — 저회전은 약하고 중회전에서 피크, 레드존에서 하락하는 실제 엔진 특성
- **엔진 RPM** — 현재 기어의 최고속 대비 속도로 계산 (기어 안에서 1,000 → 10,000 RPM까지 올라가고, 업시프트하면 떨어짐)
- **6단 변속기** — 기어비에 따라 저단은 가속력이, 고단은 최고속이 높아짐
- 기어별 최고 속도 제한
- 안티롤바(Anti-roll bar)로 코너링 시 차체 롤 억제
- 무게중심을 낮춰 주행 안정성 확보
- 엔진 회전수(RPM)에 따른 사운드 피치 변화

### 주행 보조 (플레이어 · AI 공통)
- **트랙션 컨트롤** — 바퀴의 슬립량(`WheelHit.forwardSlip`)을 감지해, 헛도는 만큼 구동 토크를 자동으로 줄여 접지력을 회복
- **속도 감응 조향** — 속도가 올라갈수록 조향각을 점진적으로 줄여(저속 30° → 고속 8°) 고속 주행 안정성 확보
- **다운포스** — 속도에 비례해 차체를 노면으로 눌러 고속 코너링 접지력 확보
- **부드러운 속도 제한** — 기어를 내려 그 기어의 최고속보다 빠른 상태가 되면, 속도를 즉시 잘라내지 않고 서서히 감속(엔진 브레이크처럼)

### 플레이어 기능
- 수동 변속 (순차 변속 + 직접 선택)
- **부스터** — 게이지 소모 및 자동 충전. 가속을 강하게 해 주지만, 기어 최고속(최고 RPM)에 닿으면 더 밀어 주지 않습니다 (실제 F1의 ERS처럼 가속만 도움 — 엔진 회전 한계를 넘는 속도는 낼 수 없음)
- **회전수 제한기** — 최고 RPM에서 엔진 힘을 짧게 끊었다 이어 RPM 바늘과 엔진음이 떨림
- **뒷바퀴 한정 드리프트** — 앞바퀴 그립은 유지한 채 뒷바퀴 그립만 낮추고 뒷바퀴에 핸드브레이크를 걸어, 조향을 잃지 않고 차체 뒤쪽만 미끄러짐
- 0→100km/h 가속 시간 실시간 측정
- `R` 키로 트랙 복귀 (트랙 경로의 바로 다음 지점, 보통 40 m 이내로 이동)
- 맵 밖으로 떨어지면 자동으로 트랙에 복귀

### AI 주행
- 씬(`SampleScene`)에는 `ComputerCarController`가 붙은 AI 차량 6대가 배치되어 있습니다.
- **웨이포인트 추종** — 트랙 경로를 순서대로 따라 주행
- **앞을 보는 조향** — 속도에 맞춰 경로 위 조금 앞의 점(약 0.8초 뒤 위치)을 보고 조향해 지그재그 없이 주행
- **코너 예측 감속** — 앞으로 250 m까지 경로의 곡선 반지름을 재서, 타이어가 버틸 수 있는 코너 속도(√(접지력 × g × 반지름))와 남은 거리로 미리 감속
- **충돌 회피** — `SphereCast`로 전방 차량을 감지(속도에 비례해 약 1초 앞까지)해, 앞차 속도에 맞춰 따라가며 회피 조향
- **뭉침 방지** — 차량마다 좌우 주행 라인과 최고 속도에 편차를 부여
- **코스 이탈 복구** — 트랙에 끼이거나, 경로를 크게 벗어나거나, 뒤집히면 일정 시간 후 경로 위로 복귀 (맵 밖으로 떨어지면 즉시 복귀)
- **차 모델별 무게중심** — 무게중심을 바퀴 높이 기준으로 잡아, 바퀴 위치가 다른 차 모델도 쉽게 넘어지지 않음
- **러버밴딩** — 플레이어와의 격차에 따라 최고속을 ±15% 범위에서 보정해 접전 유지
- 속도 기반 자동 변속
- 플레이어와 **동일한 엔진·기어·접지 설정**을 사용 (성능이 아닌 주행 실력으로 승부)

### 레이스 시스템
- **경로 투영 방식 랩 카운트** — 차량 위치를 트랙 경로 위로 투영해 진행도를 계산하므로, 어떤 주행 라인으로 달려도 랩과 순위가 정확하게 집계됨 (총 5바퀴)
- 실시간 순위 계산 — 완주 차량은 완주 시간순, 미완주 차량은 트랙 진행도순
- 레이스 종료 시 최종 순위 표시

## 트랙 경로와 테스트 결과

- **트랙 경로**: 씬의 `TrackPath` 오브젝트(`WaypointPath`)에 도로 중앙선을 따라 40 m 간격의 웨이포인트 679개가 들어 있습니다. 첫 지점이 결승선(`FinalLine`) 위치이고, 한 바퀴는 약 27 km입니다. 모든 차(플레이어·AI)가 이 경로로 랩·순위·복귀 위치를 계산합니다.
  - 이 경로는 도로 충돌체(`Track/g Road`)를 10 m 간격으로 측정해 만든 중앙선입니다. 모든 지점이 도로 위에 있고, 도로 가장자리까지 50 m 이상 여유가 있습니다.
- **트랙 길이**: 한 바퀴가 약 27 km라서 5바퀴를 실제 속도로 완주하려면 수십 분이 걸립니다.
- **도로 밖**: 고리 모양 도로 안쪽(인필드)에는 바닥이 없습니다. 도로를 벗어나 떨어지면 자동으로 트랙에 복귀합니다.

Unity 6000.0.32f1에서 `SampleScene`을 실제로 실행하는 자동 플레이 테스트(53개 항목)로 확인했습니다. (키 입력은 시험용으로 주입했습니다.)

- 정상 확인: 가속·기어 변속(`E`/`Q`/`1`~`6`)·조향·부스터·브레이크·드리프트 핸드브레이크, RPM 상승과 업시프트 시 하강, 회전수 제한기, `R` 복귀, 맵 밖 추락 시 자동 복귀, `Esc` 일시정지, 랩 카운트(결승선 통과마다 +1)와 5바퀴 완주, 최종 순위(7대), 완주 후 `Enter` 재시작
- 가속: 0→100km/h 약 4.5초 (레드존 근처에서 한 번씩 업시프트), 부스터 없이 최고 약 295km/h (300에 수렴), 부스터 사용 시 300km/h까지 약 10초
- AI: 6대 평균 약 240km/h, 최고 약 280~300km/h. 러버밴딩을 끄고 재면 각 차의 최고 속도가 설계값(300km/h × 차마다 96~100%)과 같습니다. 게임 시간 6분 주행 테스트를 여러 번 돌려 뒤집힘·추락 없이 주행하는 것을 확인했습니다.

## 수정 기록 (2026-11 점검)

자동 플레이 테스트를 만들어 돌리며 아래를 고쳤고, 고칠 때마다 같은 테스트로 다시 확인했습니다.

- **AI 경로**: AI가 따라가던 체크포인트 4개의 직선 경로가 도로 위가 아니라 고리 안쪽 허공을 가로질러, AI가 출발 직후 약 8 km 앞으로 순간이동하거나 도로 밖으로 떨어졌습니다 → 도로 중앙선을 따르는 `TrackPath`(웨이포인트 679개)를 추가
- **AI가 넘어짐**: 차 모델 두 종류가 섞여 있는데 무게중심을 같은 값으로 정해 한쪽 모델이 자주 넘어졌습니다 → 바퀴 높이 기준으로 무게중심 계산, 뒤집힌 차는 자동 복구
- **AI가 느림 (평균 약 130km/h)**: 코너 감속이 바로 앞 점 하나만 보고 직선에서도 브레이크를 밟았고, 앞차를 만나면 "내 현재 속도"를 상한으로 써서 줄지어 점점 느려졌습니다 → 곡선 반지름 기반 코너 감속, 앞을 보는 조향, 앞차 속도 추종, 속도 비례 감지 거리 (평균 약 240km/h)
- **기어 느낌**: 엔진 RPM이 실제로는 항상 최저값에 붙어 있어 엔진 힘과 소리가 기어와 무관했습니다 → 기어 최고속 대비 속도로 RPM 계산, 화면 RPM·`SHIFT UP` 표시, 회전수 제한기 추가
- **부스터**: 기어 최고속보다 60km/h 더 빨라질 수 있었습니다(최고 약 360km/h) → 실제 차처럼 가속만 도움
- **Shift 핸드브레이크**가 같은 프레임에 0으로 덮어써져 적용되지 않던 문제
- **`R` 복귀**가 다음 체크포인트로 최대 약 12 km를 건너뛰던 문제, 맵 밖으로 떨어지면 끝없이 추락하던 문제 (자동 복귀 추가)
- **재시작**: `RestartGame()`이 연결되지 않았고 호출해도 시간·상태가 초기화되지 않던 문제 → 완주 후 `Enter`로 재시작
- **0→100 표시**가 조건 없이 갑자기 나타나던 것처럼 보이던 문제 → 측정 조건 안내와 측정 중 시간 표시

## 향후 계획 — F1식 변속기 (B안)

지금 변속기는 일반 스포츠카에 가까운 6단입니다. 기어를 올리면 RPM이 약 28% 떨어지고(10,000 → 약 7,200), 0→100km/h는 약 4.5초입니다. 실제 F1에 더 가깝게 만들기 위한 다음 단계 계획입니다.

- **8단 변속기와 촘촘한 기어비**: 기어를 올릴 때 RPM이 약 15%만 떨어져서 높은 회전수를 유지
- **더 강한 엔진**: 0→100km/h를 약 2.5~3초로
- 숫자키 직접 선택을 `1`~`8`로 확장하고, 화면에 F1 스티어링휠 같은 변속 표시등(시프트 라이트) 추가
- 차 7대(플레이어·AI)의 기어 설정을 함께 바꾸고, AI의 자동 변속과 속도를 다시 맞춤
- 바꾼 뒤 자동 플레이 테스트로 가속·최고속·AI 주행을 다시 확인

## 트랙 경로 편집 (선택 사항)

AI 주행 경로를 더 촘촘하게 만들고 싶다면:

1. 빈 GameObject를 만들고 `WaypointPath` 컴포넌트를 추가합니다.
2. 그 **자식**으로 빈 오브젝트를 트랙을 따라 순서대로 배치합니다. (첫 자식 = 출발/결승선)
3. Scene 뷰에 경로가 청록색 선으로 표시되어 눈으로 확인하며 조정할 수 있습니다.
4. 컴포넌트의 톱니바퀴 메뉴 ▸ **"웨이포인트 촘촘하게"** 를 누르면 중간점이 자동 삽입됩니다.

씬에는 이미 도로 중앙선을 따르는 `TrackPath`가 들어 있습니다. `WaypointPath`가 없으면 AI 차의 `targetPositions`(체크포인트 4개)를 대신 사용합니다.
